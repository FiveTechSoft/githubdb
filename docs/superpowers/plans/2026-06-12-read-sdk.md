# githubDB Read SDK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the fast-read-path SDKs for JavaScript, Python and PHP per spec `docs/superpowers/specs/2026-06-12-githubdb-read-sdk-design.md`.

**Architecture:** Three independent packages under `sdk/{js,python,php}`, identical semantics: raw-CDN reads with shard merging, portable base64-float32 vector decode, client-side cosine search with optional/injectable local embedders, and a `query()` write convenience (dispatch + poll). HTTP and embedders injectable everywhere; tests run with zero network.

**Tech Stack:** JS: ESM, node:test, optional peer `@huggingface/transformers`. Python: pyproject (hatchling or setuptools), pytest, optional extra `sentence-transformers`. PHP 8.1+: PSR-4, PHPUnit via phpunit.phar (no composer on dev machine), optional `codewithkyrian/transformers`.

**Spec is the source of truth** for API names, error messages, model names/prefixes, and test coverage matrix. Each task below builds one SDK end-to-end (TDD: tests use injected fakes; no network).

---

### Task 1: JavaScript SDK (`sdk/js/`)

**Files:** package.json (name `githubdb-sdk`, type module, scripts.test `node --test "test/*.test.js"`), src/{index.js,client.js,table.js,vectors.js,embed.js}, test/{client.test.js,table.test.js,vectors.test.js}.

- vectors.js: `encodeVector`, `decodeVector(b64, dims?)`, `toVector`, `cosineSim` — browser-safe (no Buffer; use atob fallback to globalThis.Buffer when atob absent in old Node, but Node 18+ has atob).
- client.js: `GithubDB` class per spec API table; raw CDN vs API-contents (token); per-instance cache; `refresh`; `query()` dispatch+poll with injectable fetch + sleep fn (tests fake timers by injecting `sleep`).
- table.js: `Table` with columns/rows/objects()/search(); first VECTOR(n) column; where-predicate pre-filter; stable ordering; `{row, score}` results.
- embed.js: lazy dynamic import of `@huggingface/transformers`, `Xenova/multilingual-e5-small`, `query: ` prefix; instructive error if module missing; embedder injectable via constructor option `embedder`.
- Tests per spec coverage matrix (12+ tests), all with injected fetch fixtures (simple db, sharded db, vector db 3-dims) and fake embedder.

Steps: write tests → fail → implement → `npm test` green inside sdk/js. NO git commit (controller commits).

### Task 2: Python SDK (`sdk/python/`)

**Files:** pyproject.toml (name `githubdb-sdk`, module `githubdb_sdk`, optional-dependencies embed=[sentence-transformers], pytest in dev), githubdb_sdk/{__init__.py,client.py,table.py,vectors.py,embed.py}, tests/test_{client,table,vectors}.py.

Same semantics as Task 1; transport injectable `(method, url, headers, body) -> (status, bytes)`; vectors via `struct`/`array` (no numpy); embed.py lazy-imports sentence_transformers, model `intfloat/multilingual-e5-small`, `query: ` prefix. `query()` uses transport + injectable sleep. Run with `python -m pytest sdk/python/tests -q` (pip install pytest if absent). NO git commit.

### Task 3: PHP SDK (`sdk/php/`)

**Files:** composer.json (name `githubdb/sdk`, PSR-4 `GithubDB\\` -> src/, suggest codewithkyrian/transformers, require-dev phpunit), src/{GithubDB.php,Table.php,Vectors.php,Embedder.php}, tests/{GithubDBTest.php,TableTest.php,VectorsTest.php}, phpunit.xml.

Same semantics; httpClient injectable callable `(string $method, string $url, array $headers, ?string $body): array{int,string}`; vectors via `unpack('g*')`; Embedder lazy class_exists check with instructive error; `query()` with injectable sleep callable. PHPUnit: download phpunit.phar (11.x for PHP 8.2) into sdk/php/tools/ (gitignored), run `php tools/phpunit.phar`. NO git commit.

### Task 4: CI + docs + commit + E2E (controller)

- `.github/workflows/sdk-tests.yml`: on push/PR paths sdk/**; three jobs: node 20 (`npm ci && npm test` in sdk/js), python 3.11 (`pip install -e sdk/python[dev] pytest && pytest`), php 8.2 (setup-php, phpunit.phar cached or composer-less run). Keep simple.
- `docs/sdk.md` Pages page + README "SDKs" section + docs/index.md link.
- Single commit(s) by controller; push.
- E2E real (controller): tiny Node script + Python script + PHP script against FiveTechSoft/githubdb reading `example.docs` and running `search` with a precomputed vector (decode one stored embedding as the query → its own row must rank top-1). No model downloads needed.
